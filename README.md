# ROS Migration Doctor - RMD  (v0.0)
An open-source tool that scans legacy ROS 1 codebases and outputs a migration risk report.

**Current status**: Prototype phase — not ready for production.

## What this does
- Scans ROS 1 package structure
- Identifies automatic migration candidates
- Flags high-risk modules that need manual rewrite
- Outputs a JSON report with estimated migration effort

## What this does NOT do
- Does not perform actual migration
- Does not guarantee accuracy
- Does not replace professional consultation
